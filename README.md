# Manikanta Shanigaram — Portfolio

A sleek, animated personal portfolio website built with pure HTML, CSS, and JavaScript.

## ✨ Features

- Custom animated cursor
- Typewriter hero text
- Scroll-triggered reveal animations
- Animated skill bars & counters
- Parallax orb backgrounds
- Mobile responsive with hamburger menu
- Smooth scrolling navigation
- Magnetic contact email effect
- Noise texture overlay for depth

## 🚀 Getting Started

Just open `index.html` in any browser — no build step required.

## 📁 Files

```
├── index.html   # Main HTML structure
├── style.css    # All styles & animations
├── script.js    # Interactivity & effects
└── README.md
```

## 🌐 Deploying to GitHub Pages

1. Create a new GitHub repository (e.g. `portfolio`)
2. Push all files:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
   git push -u origin main
   ```
3. Go to **Settings → Pages → Source → main branch**
4. Your site will be live at `https://YOUR_USERNAME.github.io/portfolio`

## 🎨 Customization

- **Projects**: Edit the `.project-item` blocks in `index.html`
- **Skills**: Update the `data-width` values in `.skill-fill` for skill bar percentages
- **Colors**: Edit CSS variables in `:root` in `style.css`
- **Contact**: Replace the email in the `href="mailto:..."` link
- **Social links**: Update the anchor tags in `.contact-socials`
